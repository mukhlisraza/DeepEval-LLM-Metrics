# DeepEval-LLM-Metrics

## Description
DeepEval-LLM-Metrics is a tool designed to evaluate the performance and biases of large language models (LLMs). It aims to provide a comprehensive analysis of LLMs by assessing various metrics and tasks.

## Installation
To install the necessary dependencies, run the following command:
```bash
pip install -r requirements.txt
```

## Usage
To evaluate an LLM using DeepEval-LLM-Metrics, follow these steps:
1. Clone the repository:
    ```bash
    git clone https://github.com/mukhlisraza/DeepEval-LLM-Metrics.git
    cd DeepEval-LLM-Metrics
    ```
2. Run the evaluation script with the desired parameters:
    ```bash
    python evaluate.py --model <model_name> --task <task_name>
    ```
